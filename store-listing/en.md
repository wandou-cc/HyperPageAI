# HyperPage AI

## Short description

Select any page element, then translate, explain, summarize, polish, copy, hide, or extract its text with AI.

## Description

HyperPage AI provides a lightweight floating toolkit for the exact page element you select.

- Open the toolkit from its persistent launcher in the lower-right corner.
- Select one text block, image, video frame, canvas, form field, or interface region.
- Copy its readable text or visible screenshot.
- Temporarily hide distracting elements and undo the change.
- Translate, explain, summarize, polish, and ask custom questions.
- Extract text from visual content with a vision-capable model.
- Show quick-action results in a floating window or insert them beside the source content.
- Replace editable text only after explicit confirmation.

Bring your own OpenAI-compatible Base URL, API Key, and model. HyperPage AI has no application backend, analytics, ads, or account requirement.

## Permission justification

- Website access: displays tools, selects elements, and captures only user-requested visible regions on regular HTTP/HTTPS pages without repeated per-tab authorization.
- `storage`: keeps provider and language settings in the current Chrome profile.
- `clipboardWrite`: copies selected text, screenshots, and AI results.
